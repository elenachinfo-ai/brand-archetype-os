# Исследование: Тесты на архетипы бренда — примеры и паттерны

## Дата: 2026-05-11
## Цель: Найти лучшие примеры тестов для вдохновения при создании полноценного теста в ArchetypeOS

---

## Топ-примеры (по посещаемости / узнаваемости)

### 1. 16personalities.com — золотой стандарт UX для тестов
- **Формат:** 60 вопросов, по одному на экран
- **UI:**
  - Тонкий progress bar сверху (заполняется плавно)
  - Вопрос по центру, крупный шрифт
  - 5-point Likert scale: Strongly Disagree → Strongly Agree (кнопки или слайдер)
  - Плавная анимация сдвига при переходе
  - Навигация: можно вернуться назад
  - Нет кнопки "далее" — ответ сразу переключает на следующий вопрос
- **Результат:** Страница с процентами по 4 осям, красочный аватар типа, подробное описание
- **Почему работает:** Минимум трения, один фокус, быстрая обратная связь

### 2. Brand Personality Quiz (brandpersonalityquiz.com)
- **Формат:** 7 вопросов
- **UI:**
  - Drag-and-drop ранжирование: 12 вариантов ответа на вопрос, нужно расставить по релевантности
  - Простой clean-дизайн, много воздуха
  - Каждый вопрос — сценарий (tagline, greatest strength, worst thing, success measure, employee of the year, strategy, $1M gift)
- **Проблемы:** Drag-and-drop на мобильном неудобен. 12 вариантов перегружают.
- **Плюсы:** Вопросы близки к бизнес-реальности, не абстрактны

### 3. How to Fascinate (howtofascinate.com / Sally Hogshead)
- **Формат:** ~28 вопросов, 5 минут
- **UI:**
  - Яркие цвета по категориям (Innovation, Passion, Power, Prestige, Trust, Mystique, Alert)
  - Вопросы в стиле "A vs B" — выбор между двумя полярными утверждениями
  - Результат: комбинация Primary + Secondary Advantage = Archetype
  - Визуальный "heat map" для команд
- **Плюсы:** Дуальный выбор быстрее Likert. Визуализация результатов сильная.

### 4. Pearson-Marr Archetype Indicator (PMAI)
- **Формат:** 96 вопросов (профессиональный инструмент)
- **UI:** Не доступен бесплатно онлайн, но известна структура:
  - Likert scale (1-5) на каждое утверждение
  - Утверждения привязаны к 12 архетипам
  - Результат: профиль по всем 12 архетипам (не один победитель)
- **Проблема:** 96 вопросов — это утомительно без геймификации

### 5. Liz Watt Major Archetype Quiz (learn.lizwatt.com)
- **Формат:** 13 вопросов, 2-3 минуты
- **UI:** Стандартный квиз-формат, после регистрации email
- **Плюсы:** Быстрый, низкий порог входа

### 6. LonerWolf Psychological Archetype Test (lonerwolf.com)
- **Формат:** ~20 вопросов
- **UI:** Стандартный радио-кнопки, один вопрос на страницу
- **Плюсы:** Хорошие описания, spiritual-контент, viral-потенциал

## Ключевые инсайты для ArchetypeOS

### 1. Длина теста
- 96 вопросов — это 15-20 минут. Без геймификации 70% дропаут.
- **Решение:** Разбить на 4 блока по 24 вопроса (или 8×12). Между блоками — "чекпоинт" с промежуточным результатом.
- Альтернатива: адаптивный тест — сначала широкий скрининг (12 вопросов), потом углубление по топ-3 архетипам (ещё 24).

### 2. Формат вопросов для нашей системы
Лучшая комбинация для 4D-вектора:
- **Сценарные вопросы** (как Brand Personality Quiz): "Ваша компания получила $1M..." — ответы смещают вектор
- **A vs B** для быстрого сканирования: "Контроль vs Свобода", "Действие vs Анализ"
- **Likert 5-point** для точной калибровки: "Наш бренд всегда берёт ответственность на себя"

Каждый вопрос должен влиять на 1-2 измерения вектора (Control, Energy, Focus, Method).

### 3. Разделение панелей (по задумке пользователя)
- **Левая панель (тест):** Вопрос + варианты ответа. Минимум отвлекающего.
- **Правая панель (визуал):** Canvas-поле с 12 точками + позиция бренда. Живая обратная связь: каждый ответ = точка движется.
- **HUD:** Прогресс теста, confidence, текущий топ-3.

### 4. Геймификация
- Каждый ответ = "импульс" на поле, точка архетипа подсвечивается
- Между блоками — "moment of truth": пульсация, scan-анимация (уже есть в pivot.js)
- Progress bar в стиле полукруглого датчика (как jog-dial) — вписывается в HUD-эстетику
- "Unlock" архетипов: по мере прохождения раскрываются иконки/описания

### 5. Мобильный UX
- Свайп влево/вправо для A vs B (Tinder-style, как в SPACE_CONCEPT.md)
- Карточки вопросов с жестом "смахнуть"
- Canvas-поле упрощается до компаса / радара

## Рекомендуемая структура теста (96 вопросов)

```
БЛОК 1: Ядро (12 вопросов) — 2 мин
  ├─ 6 пар A-vs-B (Control↔Freedom, Energy↔Calm, Focus↔Explore, Method↔Chaos)
  └─ 6 сценарных Likert
  → Промежуточный результат: примерный топ-3

БЛОК 2: Мотивация (24 вопроса) — 4 мин
  ├─ Цели бренда (8)
  ├─ Страхи / анти-цели (8)
  └─ Ценности (8)
  → Уточнение вектора

БЛОК 3: Поведение (24 вопроса) — 4 мин
  ├─ Как бренд принимает решения (8)
  ├─ Как бренд коммуницирует (8)
  └─ Как бренд реагирует на кризис (8)
  → Точный профиль

БЛОК 4: Визуальная идентичность (24 вопроса) — 4 мин
  ├─ Цвета, формы, типографика (12)
  ├─ Tone of voice (6)
  └─ UX-паттерны (6)
  → Финальный вектор + рекомендации по дизайну

БЛОК 5: Валидация (12 вопросов) — 2 мин
  ├─ Проверочные вопросы (инвертированные)
  └─ Самооценка по архетипам
  → Confidence score, финальный результат
```

Итого: ~16 минут. С геймификацией и живым canvas — воспринимается как 10.
