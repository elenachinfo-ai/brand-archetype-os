## Механика взаимодействия

### Вместо кликов — свайп-карточки (Tinder-style)
```
┌──────────────────────────────┐
│  ← Скорее нет    Скорее да → │
│                              │
│     "Мы действуем            │
│      решительно"             │
│                              │
│  ◄─────── ● ───────►        │
│     1  2  3  4  5           │
└──────────────────────────────┘
```

### Живая звёздная карта (правая панель)
```
•  •    ✦    •  •
  •  •  ✦  •  •
•  ✦  ★  ✦  •
  •  •  ✦  •  •
•  •    ✧    •  •
```
- 12 звёзд = архетипы
- ★ = позиция бренда (пульсирует)
- ✦ = ближайшие архетипы (связи-лучи)
- Каждый ответ = звезда меняет яркость
